# سیستم فاکتور فروشگاه دوربین

سیستم مدیریت فاکتور و پرداخت آنلاین برای فروشگاه دوربین با اتصال به درگاه زرین‌پال.

## ویژگی‌ها

- **مدیریت محصولات**: افزودن، ویرایش و حذف محصولات
- **ایجاد فاکتور**: ساخت فاکتور با سبد خرید برای مشتریان
- **پرداخت آنلاین**: اتصال به درگاه پرداخت زرین‌پال
- **تاریخچه فاکتورها**: مشاهده و مدیریت فاکتورهای قبلی
- **احراز هویت امن**: سیستم لاگین برای ادمین
- **رابط کاربری فارسی**: طراحی RTL با زبان فارسی

## تکنولوژی‌ها

- **Frontend**: Next.js 14 (بدون TypeScript)
- **Backend**: Next.js API Routes (Node.js)
- **Database**: MongoDB
- **Payment**: Zarinpal API
- **Hosting**: Vercel

## نصب و راه‌اندازی

### 1. کلون کردن پروژه

```bash
cd camera-invoice-app
```

### 2. نصب وابستگی‌ها

```bash
npm install
```

### 3. تنظیم متغیرهای محیطی

فایل `.env.local` را ایجاد کنید و مقادیر زیر را وارد کنید:

```env
MONGODB_URI=mongodb://localhost:27017/camera-invoice-app
JWT_SECRET=your-secret-key-change-this-in-production
ZARINPAL_MERCHANT_ID=your-zarinpal-merchant-id
ZARINPAL_MODE=sandbox
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

### 4. اتصال به MongoDB

برای استفاده محلی، MongoDB را نصب کنید یا از MongoDB Atlas استفاده کنید.

### 5. ایجاد کاربر ادمین

```bash
node scripts/seed-admin.js
```

این دستور یک کاربر ادمین با مشخصات زیر ایجاد می‌کند:
- **نام کاربری**: admin
- **رمز عبور**: admin123

⚠️ **مهم**: پس از اولین ورود، رمز عبور را تغییر دهید.

### 6. اجرای پروژه

```bash
npm run dev
```

پروژه در آدرس `http://localhost:3000` در دسترس خواهد بود.

## راهنمای استفاده

### 1. ورود به سیستم

- به آدرس `http://localhost:3000/login` بروید
- با نام کاربری `admin` و رمز عبور `admin123` وارد شوید

### 2. مدیریت محصولات

- به بخش **مدیریت محصولات** در داشبورد بروید
- برای افزودن محصول جدید روی دکمه "افزودن محصول" کلیک کنید
- اطلاعات محصول (نام، قیمت، توضیحات، لینک تصویر) را وارد کنید
- محصولات را ویرایش یا حذف کنید

### 3. ایجاد فاکتور

- به بخش **ایجاد فاکتور جدید** بروید
- اطلاعات مشتری (نام و شماره تماس) را وارد کنید
- محصولات را از لیست انتخاب کرده و به سبد خرید اضافه کنید
- تعداد هر محصول را تنظیم کنید
- روی دکمه "ایجاد فاکتور" کلیک کنید
- لینک پرداخت را بسازید و برای مشتری ارسال کنید

### 4. مشاهده فاکتور

- فاکتورها را از بخش **تاریخچه فاکتورها** مشاهده کنید
- روی دکمه "مشاهده" کلیک کنید
- لینک پرداخت را کپی کنید یا مستقیماً پرداخت کنید

### 5. صفحه فاکتور برای مشتری

- مشتری می‌تواند با لینک فاکتور وارد صفحه پرداخت شود
- جزئیات فاکتور را مشاهده کند
- لینک پرداخت را کپی کند یا مستقیماً پرداخت کند

## تنظیم زرین‌پال

### 1. ثبت‌نام در زرین‌پال

به سایت [zarinpal.com](https://www.zarinpal.com) بروید و ثبت‌نام کنید.

### 2. دریافت Merchant ID

- پس از ثبت‌نام، وارد پنل شوید
- از بخش تنظیمات، Merchant ID را کپی کنید
- Merchant ID را در فایل `.env.local` قرار دهید

### 3. حالت Sandbox

برای تست، از حالت sandbox استفاده کنید:
```env
ZARINPAL_MODE=sandbox
```

برای استفاده در محیط تولید:
```env
ZARINPAL_MODE=production
```

## دیپلوی روی Vercel

### 1. اتصال به Vercel

```bash
npm install -g vercel
vercel login
```

### 2. دیپلوی

```bash
vercel
```

### 3. تنظیم Environment Variables

در پنل Vercel:
- به بخش Settings > Environment Variables بروید
- متغیرهای محیطی را اضافه کنید:
  - `MONGODB_URI`: آدرس اتصال به MongoDB (از MongoDB Atlas استفاده کنید)
  - `JWT_SECRET`: یک کلید امن تصادفی
  - `ZARINPAL_MERCHANT_ID`: Merchant ID زرین‌پال
  - `ZARINPAL_MODE`: production یا sandbox
  - `NEXT_PUBLIC_BASE_URL`: آدرس سایت شما در Vercel

### 4. دیپلوی مجدد

```bash
vercel --prod
```

## امنیت

- رمز عبور با bcrypt هش می‌شود
- JWT برای احراز هویت استفاده می‌شود
- Cookieهای HTTP-only برای امنیت جلسات
- محافظت از API routes با احراز هویت

## عیب‌یابی

### خطا در اتصال به MongoDB

- مطمئن شوید MongoDB در حال اجراست
- MONGODB_URI را بررسی کنید
- اگر از MongoDB Atlas استفاده می‌کنید، IP whitelist را تنظیم کنید

### خطا در پرداخت زرین‌پال

- Merchant ID را بررسی کنید
- حالت sandbox/production را بررسی کنید
- callback URL را در تنظیمات زرین‌پال وارد کنید

### خطا در احراز هویت

- مطمئن شوید کاربر ادمین ایجاد شده است
- cookieها را پاک کنید و مجدداً تلاش کنید
- JWT_SECRET را بررسی کنید
